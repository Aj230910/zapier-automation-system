# zapier-automation-system
## 📌 Overview

The project is designed to show an end-to-end automation workflow using Zapier. The project will include Google Forms, Google Sheets, Gmail, and Twilio for user registration and notifications.

## ⚙️ Workflow

1. User submits Google Form
2. Data stored in Google Sheets
3. Email notification sent via Gmail
4. SMS alert sent via Twilio

## 🛠️ Tools Used

* Zapier
* Google Forms
* Google Sheets
* Gmail
* Twilio

## 💡 Features

* Real-time automation
* Dynamic email and SMS sending
* No-code workflow integration
